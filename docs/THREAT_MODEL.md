# Threat Model: AgentBreak Platform

**Target System:** AgentBreak Platform (FastAPI API, SQLite/Postgres DB, React Frontend, Acme Sandbox Agent)  
**Scope:** Hackathon evaluation version of the defensive red-teaming platform.  
**Classification:** Defensive security assessment tool.

---

| Asset ID | Asset Name | Description | Sensitivity |
|---|---|---|:---:|
| **A-1** | `GEMINI_API_KEY` | Upstream Google Gemini API secret token. | **Critical** |

## 2. Threat Actors & Capabilities

| Actor | Profile & Motivation | Capabilities / Access |
|---|---|---|
| **Actor 1: Anonymous Web Client** | External untrusted internet visitor. | Can access public network ports (HTTP/HTTPS, SSE streams). |
| **Actor 2: Authenticated Viewer** | Read-only user or executive reviewer. | Legitimate access to dashboards, reports, and attack graphs. |
| **Actor 3: Authenticated Analyst / Admin** | Authorized red-teamer or security administrator. | Full control to configure defenses, launch attacks, run replays. |
| **Actor 4: Malicious Payload in Trace** | Adversarial payload generated by attacker or retrieved from external mock email/doc. | Stored in SQLite/Postgres database, rendered in React DOM, and exported to HTML reports. |
| **Actor 5: Compromised Victim Agent** | Sandbox LLM tricked into arbitrary tool execution. | Controls parameters of tool calls within the Python runtime. |

## 3. Top Security Risks & STRIDE Classification

### Risk 1: Stored XSS via Malicious Traces (Tampering / Information Disclosure)
- **Vector:** An injection prompt containing `<script>` or `<img src=x onerror=...>` is recorded in `TraceStep.content` and rendered in the frontend or exported into the standalone HTML report.
- **Impact:** Session hijacking, token theft, or unauthorized API actions performed in the analyst's browser.
- **Control:** Strict HTML escaping on server-side report generation; prohibition of `dangerouslySetInnerHTML` with trace data; strict Content-Security-Policy (CSP) headers.

### Risk 2: Sandbox Egress & Host Escalation (Elevation of Privilege)
- **Vector:** Compromised victim agent attempts to call tools with real network URLs or local file system paths (`file:///etc/passwd`, `http://169.254.169.254`).
- **Impact:** SSRF, internal network scanning, cloud metadata exfiltration, or host file disclosure.
- **Control:** Mocked tool adapters only; runtime socket network egress guard blocking outbound connections (except authorized Gemini API domain); strict path validation.

### Risk 3: API Key & Secret Leakage (Information Disclosure)
- **Vector:** `GEMINI_API_KEY` logged in traceback output, included in serialized API responses, or committed to git.
- **Impact:** Theft of upstream LLM quota, unauthorized cloud billing.
- **Control:** Secret scrubbing in log handlers and trace serializers; `.env` git-ignored; test asserts key never appears in trace JSON or HTTP responses.

### Risk 4: Cross-Tenant / Cross-User Access (Spoofing / Elevation of Privilege)
- **Vector:** Analyst A guesses the UUID of Analyst B's campaign (`/api/campaigns/{id}`) or reads another workspace's traces.
- **Impact:** Unauthorized viewing of proprietary red-team findings.
- **Control:** User & workspace ownership fields on all models (`user_id`); strict server-side authorization checks on all routes.

### Risk 5: Resource & Financial Exhaustion / DoS (Denial of Service)
- **Vector:** An attacker loops expensive LLM calls by initiating dozens of concurrent campaigns or infinite replays.
- **Impact:** Exhaustion of Gemini API quota, high financial charges, server thread starvation.
- **Control:** Per-campaign and per-user budget counters, max iteration caps, IP/user rate limiting on campaign initiation endpoints, global kill switch.

## 4. Isolation Boundaries & Honest Limitations

1. **What Isolation Exists:**
   - **Process-level isolation & mocked adapters:** Tools do not execute OS commands or make raw network requests. All email, customer databases, and documents are synthetic dictionaries in RAM.
   - **Socket-level egress blocker:** Python runtime socket hook preventing unauthorized outbound TCP/UDP connections.
   - **Application-layer RBAC:** Server-enforced role checks and workspace ownership filters.
2. **What Isolation Does NOT Exist:**
   - **Not a hardware hypervisor / VM boundary:** The sandbox runs in the same Python process as the red-team orchestrator. A low-level Python runtime exploit (e.g. C-extension vulnerability) could compromise the process.
   - **Not an air-gapped system:** Upstream HTTPS connectivity to Google Gemini API is required for live testing.
   - **No external third-party penetration test:** Platform hardening is implemented to defensible hackathon standards.
